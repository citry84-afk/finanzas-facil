Política editorialMétodo y fuentes

Qué es FinanzasFácil

Es una web con calculadoras y guías educativas para dudas cotidianas: entender el salario neto, preparar una estimación como autónomo, ordenar un mes de gastos o saber qué conviene mirar antes de contratar una hipoteca.

Las herramientas básicas funcionan sin registro. El control de gastos guarda la información en el propio dispositivo, no requiere conectar bancos y permite exportar los datos cuando la persona lo necesita.

Para quién está hecho

Para quien quiere una primera explicación clara antes de abrir una norma, hablar con una gestoría o tomar una decisión. No hace falta conocer terminología financiera: la prioridad es entender el siguiente paso, no rellenar la pantalla de indicadores.

  • Personas que quieren pasar de salario bruto a neto con un cálculo orientativo.
  • Autónomos que necesitan separar conceptos como cuota, IRPF, IVA, gastos y caja.
  • Hogares que buscan una forma sencilla de ver ingresos, gastos y margen mensual.

Cómo se crea el contenido

Las guías se escriben para responder una duda concreta y se revisan antes de publicar. En asuntos regulados se priorizan fuentes públicas primarias, como la Agencia Tributaria, la Seguridad Social, el BOE o el Banco de España. Las páginas que dependen de un ejercicio concreto señalan su fecha de revisión y enlazan la fuente cuando ayuda a comprobarla.

Las calculadoras no son formularios oficiales. Usan supuestos visibles para producir una estimación útil y explican qué datos no pueden conocer. Cuando una URL antigua repite un tema ya cubierto, se redirige hacia la guía que se mantiene.

Transparencia: FinanzasFácil no es una gestoría, una asesoría financiera ni un despacho laboral. No emitimos dictámenes personalizados ni prometemos una cifra fiscal definitiva.

Qué puedes esperar

  • Explicaciones en español de España, con ejemplos en euros y lenguaje directo.
  • Fuentes y límites visibles cuando el tema depende de normativa.
  • Herramientas que priorizan privacidad y no piden datos bancarios.
  • Correcciones cuando una fuente, una fórmula o una explicación necesitan actualizarse.

Qué no debes esperar

  • Resultados garantizados de ahorro, inversión o fiscalidad.
  • Un sustituto de una nómina, una declaración presentada o una consulta profesional.
  • Reseñas inventadas, cifras de usuarios sin verificar o mensajes de urgencia para hacer clic.

Cómo avisar de un error

Las correcciones son parte del trabajo del proyecto. Si detectas una cifra desactualizada, un enlace oficial roto o un resultado extraño, escribe a lipastudios4@gmail.com con la URL y una breve explicación. Para una calculadora, incluye datos de ejemplo, nunca información personal sensible.

La política editorial explica el criterio de revisión y la página de método y fuentes detalla cómo leer los resultados orientativos.
