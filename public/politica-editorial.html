Cómo se publica, actualiza y corrige FinanzasFácil

Las guías y calculadoras son educativas. Esta página cuenta quién las mantiene, qué fuentes se usan y dónde están sus límites.

Actualizado el 16 de agosto de 2026

Responsable y propósito

FinanzasFácil es un proyecto de LIPA Studios mantenido por Luis Alberto Moratalla. Se crean calculadoras y guías sobre nómina, autónomos, hipoteca, ahorro y control de gastos para ayudar a entender una situación antes de tomar decisiones.

El contenido no sustituye asesoramiento fiscal, financiero, laboral o legal personalizado. Cuando una respuesta depende de datos individuales, se indica ese límite en lugar de presentar una estimación como si fuera definitiva.

Cómo se elige y escribe una guía

Una página debe responder una duda reconocible y aportar un mecanismo, una explicación o una herramienta que ayude a avanzar. No se publican variantes casi idénticas por cada año o palabra clave: si una guía ya cubre la intención, se mejora o se redirige hacia ella.

En temas regulados se priorizan fuentes públicas primarias: Agencia Tributaria, Seguridad Social, BOE y Banco de España. Las guías anuales muestran una fecha de revisión y enlazan las fuentes importantes para que cualquiera pueda comprobarlas.

Cómo funcionan las calculadoras

Una calculadora trabaja con los datos que la persona introduce y con supuestos visibles. Por eso puede ser útil para explorar escenarios, pero no conoce toda la realidad de una nómina, una declaración, una hipoteca o una actividad económica.

  • Mostramos estimaciones, no liquidaciones oficiales.
  • Explicamos los datos que pueden alterar el resultado.
  • No pedimos credenciales bancarias para usar las herramientas básicas.
  • El control de gastos puede guardar datos en el dispositivo y permite exportarlos.

Qué no hacemos

  • No inventamos usuarios, valoraciones, reseñas, premios ni resultados de ahorro.
  • No escondemos limitaciones para conseguir un clic o una suscripción.
  • No convertimos un contenido educativo en una recomendación individual.
  • No tratamos una lista general de gastos deducibles como una garantía para cada caso.

Actualizaciones y consolidación

Las páginas sobre ejercicios fiscales, plazos o importes se revisan cuando la fuente pública cambia o cuando se prepara una nueva versión anual. Si una URL antigua deja de ser la mejor respuesta, se redirige permanentemente a la versión que se mantiene. El sitemap contiene solo las páginas que queremos que los buscadores consideren canónicas.

Correcciones

Para informar de una cifra desactualizada, un enlace roto o un resultado extraño, escribe a lipastudios4@gmail.com. Incluye la URL, una descripción breve y, si se trata de una calculadora, datos de ejemplo sin información personal sensible.

Cuando una corrección sea relevante se ajustará la página, sus fuentes o sus enlaces internos. No respondemos con dictámenes sobre un caso personal por correo.

Publicidad y relaciones comerciales

La publicidad, la afiliación o cualquier contenido comercial que pueda incorporarse deben diferenciarse del contenido editorial. Ningún acuerdo comercial debe alterar una fórmula, seleccionar una fuente ni ocultar un límite. Las guías deben poder leerse y las herramientas deben poder utilizarse aunque no se muestre publicidad.

Cómo leer esta política

La página de quién mantiene FinanzasFácil explica el alcance del proyecto. La de método y fuentes reúne criterios prácticos para interpretar resultados. Si encuentras una contradicción entre estas páginas y una guía concreta, agradecemos que nos la señales.
